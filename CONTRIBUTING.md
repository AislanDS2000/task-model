# Como contribuir

Obrigado por ajudar o Task Model. Você pode abrir uma issue com sugestões, problemas encontrados e passos para reproduzi-los.

O código é público sob MIT License com Commons Clause; leia [LICENSE](LICENSE) antes de usar, modificar ou redistribuir. Essa combinação é **código-fonte disponível**, não uma licença open source aprovada pela OSI. Não é permitido vender o Task Model em si nos termos definidos pela Commons Clause.

Por enquanto, não incorporaremos pull requests com código, imagens ou documentação de terceiros. Quem contribui continua titular da própria contribuição, e a licença pública do repositório não concede automaticamente ao mantenedor o direito de incluí-la em uma edição comercial futura. Antes de aceitar contribuições, estabeleceremos um acordo separado de contribuição, com termos claros para quem contribui e para o projeto.

Você pode continuar compartilhando ideias e relatos pelas issues. Não envie segredos, dados pessoais, conversas privadas ou registros locais do aplicativo.
